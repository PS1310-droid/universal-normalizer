01_

The Steamroller

Every real API (Shopify, Salesforce, HubSpot) sends deeply nested JSON. Objects inside objects, arrays of objects. Before we touch your schema, the Steamroller recursively flattens it. A key buried at customer → location → city becomes customer_location_city. Your master schema stays flat and clean.

Input
{ "customer": { "location": { "city": "Gotham" } } }
Output
{ "customer_location_city": "Gotham" }
02_

Exact Matcher

Before we call any AI model, we strip punctuation, lowercase everything, and compare. "First_Name", "firstname", and "f-i-r-s-t-name" all match FirstName. If Python can figure it out, it does. For free, in milliseconds, with zero hallucination risk.

"telephone" → strips to "telephone" → matches "PhoneNumber"? No → goes to AI
"firstname" → strips to "firstname" → matches "FirstName"? Yes → mapped. Free.
03_

AI Mapper with Confidence Gate

Only the keys the exact matcher couldn't figure out get sent to the AI. It returns a confidence score (0 to 100) for every match. Above 85%: auto mapped into your clean output. Below 85%: flagged for human review with the suggested match attached, so your team decides, not the model. 

"ready_to_use": {
  "FirstName": "Bruce"
}

"flagged_for_review": {
  "PhoneNumber": {
    "suggested_match": "tel",
    "confidence_score": 61
  }
}

05_

Manual Mode

Already know exactly which fields map to what? Skip the AI entirely. POST a schema_map object and the API will apply it directly. No model calls, no confidence scores, instant output. Use this in production pipelines where the schema is stable and speed matters.

POST /normalize/manual

Make your first call

curl -X POST https://yourdomain.com/normalize/auto \
  -H "Content-Type: application/json" \
  -d '{
    "template_name": "shopify_customer",
    "messy_data": {
      "f_name": "Bruce",
      "tel": "555-1234"
    }
  }'
import requests

r = requests.post("https://yourdomain.com/normalize/auto",
    json={
        "template_name": "shopify_customer",
        "messy_data": {"f_name": "Bruce"}
    })
print(r.json())

Payload Formats

When calling /normalize/auto, you must provide the raw JSON object you want cleaned as messy_data. You must also tell the normalizer what your target schema looks like using either a built-in template or your own array of keys.

Using a Template

Pass template_name with the exact name of a verified template to apply its schema.

{
  "template_name": "shopify_customer",
  "messy_data": { ... }
}

Using Custom Master Keys

Alternatively, pass an array of strings as master_keys to define your custom schema on the fly.

{
  "master_keys": ["FirstName", "PhoneNumber"],
  "messy_data": { ... }
}

The Manual Endpoint

If you already know the field mapping and want to bypass the AI processing for a faster response, you can post directly to /normalize/manual. Provide a schema_map dictionary linking your intended master keys to the provided messy keys. 

curl -X POST https://yourdomain.com/normalize/manual \
  -H "Content-Type: application/json" \
  -d '{
    "schema_map": {
      "FirstName": "f_name",
      "PhoneNumber": "tel"
    },
    "messy_data": {
      "f_name": "Bruce",
      "tel": "555-1234"
    }
  }'
